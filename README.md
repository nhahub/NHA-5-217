# Automated UI Testing for an E-Commerce Website

## 📌 Project Overview

### Objective

To design and implement a clean, maintainable, and reusable automated UI testing suite for the main user journeys of a public e-commerce website using **Selenium WebDriver with Java**.

### Description

This project focuses on automating essential e-commerce user journeys to verify that the website's core functionalities work as expected.

The team follows a structured testing approach, starting with manual test case design and then converting the test cases into automated UI tests. The automation suite uses appropriate assertions and explicit waits to improve test reliability.

The project also applies the **Page Object Model (POM)** design pattern to separate page-specific elements and actions from test logic, improving code organization, maintainability, and reusability.

---

## 🎯 Scope of Testing

The project covers the following main user journeys:

| Journey | Description |
|---|---|
| **Login** | Verify login functionality using valid and invalid credentials. |
| **Product Search** | Verify that users can search for products and view relevant results. |
| **Shopping Cart** | Verify that users can add products to the cart and validate cart details. |
| **Checkout** | Verify the checkout process and validate relevant order information. |
